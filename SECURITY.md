# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/hrsather/icloud-calendar-mcp/security/advisories/new).
Do not open a public issue. Expect an initial response within a week.

## Supported versions

Only the latest release is supported.

## Handling credentials

This server needs an Apple ID and an
[app-specific password](https://support.apple.com/102654). Never share them in issues or logs.
If one leaks, revoke it at account.apple.com; changing the Apple ID password also revokes
app-specific passwords.
